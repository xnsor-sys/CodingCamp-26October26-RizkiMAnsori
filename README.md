## Daybook Expense Tracker

A lightweight expense and budget visualizer built with HTML, CSS, and vanilla JavaScript. It stores entries in your browser's local storage; no account or backend is needed.

### Use

Open `index.html` in a modern browser. Add an item name, positive amount, and category to record an expense. The total, category chart, and scrollable transaction list update immediately. Use the × button beside an entry to delete it.

Amounts are displayed in Indonesian rupiah (IDR). Enter whole rupiah values. Entries remain in local storage on the current browser and device.
